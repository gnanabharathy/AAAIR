Course Finder for health research analytics and AI

Prototype tools that help Australian health researchers find online training in advanced analytics and AI, drawing on courses selected through the AAAIR course review. Two design approaches were built and user-tested; try either.

Guided

Guided needs assessment

Answer a short series of questions about the tool you want to learn, your health focus, level, preferred format and budget. The count of matching courses updates at each step. User testers found this the more approachable starting point.

Search and filter

Course dashboard

Search and filter all 738 selected courses at once. Each course shows its enrolment status, such as open enrolment, a scheduled start date or closed, and one-off events that have already passed are hidden by default.

Course dashboard, earlier version

The first version of the dashboard, without enrolment status. Kept for comparison with the version above.

These are research prototypes from Work Package 6.4 of the AAAIR project, developed in collaboration with the Australian Research Data Commons (ARDC). The course database is dated 30 June 2026, so some details may have changed since. Check with the course provider before enrolling. Methods, reports and source material are in the project repository.
