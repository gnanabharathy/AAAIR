# AAAIR
ARDC-ADSN Advanced Analytics and AI Resource Hub

## About This Project

This repository supports the AAAIR project, which operationalises the nationally validated frameworks and reference architecture from Stage 1 into a curated, deployable set of advanced analytics, AI, data, and socio-technical resources for the People RDC Stack. Rather than building new tools from scratch, the project prioritised integrating and curating existing platforms, following a **curation-first, customisation-as-needed, development-last** approach — with strong attention to FAIR principles and interoperability. Close collaboration with ARDC and the VRE Cloud Service team ensures curated resources are deployment-ready within NeCTAR-backed environments and aligned with national research infrastructure strategy.

## Work Packages

| WP | Focus | Summary |
|----|-------|---------|
| **WP1** | Governance and Coordination | Established project governance, including a Steering Committee co-led by Professors Armstrong and Mehta with ARDC representation, working groups, role recruitment, and a Communication and Engagement Strategy. |
| **WP2** | Data Assets | Identified and curated high-value healthcare data assets, reference and synthetic datasets, metadata specifications, and FAIR-aligned data protection requirements. |
| **WP3** | Advanced Analytics Tools and Platforms | Curated statistical, computational, and domain-specific analytics tools, assessed for maturity, sustainability, licensing, and VRE deployment suitability. |
| **WP4** | AI-Focused Tools and Platforms | Curated machine learning and AI tools, models, pipelines, co-pilots, and low/no-code solutions, assessed for maturity, interoperability, and FAIR compliance. |
| **WP5** | Socio-Technical Assets: Ethics and Governance | Curated ethical frameworks, governance templates, compliance tools, and best-practice guidelines for responsible data science and AI use. |
| **WP6** | Socio-Technical Assets: Resources and Training | Curated training materials, guidelines, checklists, and governance templates; developed a pilot Personalised Recommender System (PRS) for contextualised training pathways. |
| **WP7** | Implementation, Sustainability, and Monitoring | Established deployment planning and integration pathways for NeCTAR-backed VREs, and proposed a sustainability mechanism for ongoing curation beyond the project timeline. |
