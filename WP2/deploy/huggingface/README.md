# Open Healthcare Dataset Explorer (AAAIR WP2)

Browse dataset metadata and OMOP data quality reports for NHANES, PHIDU and PTB-XL.
Prototype from the AAAIR project (Work Package 2).

- Source code and documentation: https://github.com/gnanabharathy/AAAIR/tree/main/WP2
- This Space is a hosting copy. The GitHub repository is the authoritative source.
