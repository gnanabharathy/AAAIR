# Extracting New Datasets

This guide is for adding new dataset metadata to the explorer using `extractor.py`. If you just want to browse existing datasets, see the main [README.md](README.md).

---

## How it works
---

## Prerequisites

- Python 3.9 or higher
- NVIDIA NIM API key — free at https://build.nvidia.com
- No pip installs needed — uses Python standard library only

### Set up your API key

Go to https://build.nvidia.com, sign up, and generate a free API key (starts with `nvapi-`).

```bash
cp .env.template .env
```
Open `.env` and replace `nvapi-paste-your-key-here` with your actual key.

---

## Extract a single dataset

```bash
python3 extractor.py "https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2015/DataFiles/DEMO_I.htm" "nhanes-demo-2015"
```

What happens:
1. Fetches the documentation page
2. Extracts all variables using regex
3. Sends to NIM LLM for enrichment (data type, unit, analyst notes)
4. Opens a review page — left side is the original page, right side is what was extracted
5. Asks you to confirm before saving — type `y` to save, `n` to skip

---

## Extract multiple datasets automatically

```bash
python3 extractor.py --batch datasets.csv
```
Reads all URLs from `datasets.csv` and processes them one by one. Skips any already in `schema.json` so you can stop and resume anytime.

---

## Scan NHANES for all available dataset URLs

```bash
python3 scan_nhanes.py
```
Generates `datasets_nhanes_full.csv` with all NHANES dataset URLs across all categories and years.

---

## Adding your own datasets

Open `datasets.csv` and add a row for each dataset you want to extract:
Then run:
```bash
python3 extractor.py --batch datasets.csv
```

## Project structure (extraction-related files)

### Core scripts
| File | Purpose |
|------|---------|
| `extractor.py` | Main extraction script. Fetches a dataset documentation page, extracts all variables using regex, enriches with NIM LLM, opens a review page, and saves to `schema.json` and `data.js`. |
| `scan_nhanes.py` | Scans the NHANES website across all categories (Demographics, Dietary, Examination, Laboratory, Questionnaire) and generates a CSV of all available dataset URLs. |

### Auto-generated files (do not edit manually)
| File | Purpose |
|------|---------|
| `schema.json` | Stores all extracted metadata for every dataset. Updated automatically by `extractor.py` after each confirmed extraction. This is what `schema.html` reads to display variable tables. |
| `data.js` | Stores the dataset list (name, description, subtypes, tasks, source, last updated, doc URL) used to render cards in `index.html`. Updated automatically alongside `schema.json`. |
| `review_*.html` | Temporary review pages generated after each extraction. Left panel shows the original documentation page, right panel shows what the LLM extracted. Used to verify extraction quality before saving. |
| `datasets_nhanes_full.csv` | Generated by `scan_nhanes.py` — full list of all NHANES dataset URLs. |

### Config files
| File | Purpose |
|------|---------|
| `.env` | Your NIM API key and model config. Never share or upload this file. |
| `.env.template` | Template for `.env` — safe to share and commit to GitHub. |
| `datasets.csv` | Your list of dataset IDs and URLs to extract. Add one row per dataset. |

```json
    "name": "NHANES Demographics 2015-16",
    "desc": "One sentence description of the dataset.",

    "tasks": ["classification", "regression"],
    "url": "https://wwwn.cdc.gov/...",

    "variable_count": 47,
    "variables": [
      {
        "name": "RIAGENDR",
        "label": "Gender",
        "english_text": "Gender of the sample person.",
        "target": "Both males and females 0 YEARS - 150 YEARS",
        "count": 9971,
        "values": [
          {"code": "1", "desc": "Male",    "count": 4925},
          {"code": "2", "desc": "Female",  "count": 5046},
          {"code": ".", "desc": "Missing", "count": 0}
        ],
        "data_type": "Binary",
        "unit": null,
        "notes": "Analyst tip about this variable."
      }
    ]
  }
}
```
